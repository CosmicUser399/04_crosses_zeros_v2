# Крестики-нолики 5×5

Настольная игра «Крестики-нолики» на поле 5×5 с графическим
интерфейсом на Tkinter и встроенным эвристическим ИИ-противником.

## Описание

Игрок играет крестиками (X), компьютер — ноликами (O). Победу
одерживает тот, кто первым выстраивает 5 символов подряд по
горизонтали, вертикали, диагонали или обратной диагонали.
ИИ детерминирован: поведение зависит от выбранного уровня
сложности (см. раздел «Уровни сложности»).

## Уровни сложности

Уровень выбирается в выпадающем списке перед началом новой партии.
Изменение применяется только при нажатии «Новая игра».

| Уровень | Победный ход | Блокировка | Стратегия |
|---------|:------------:|:----------:|-----------|
| Простой | ✓ | ✗ | Ослабленная эвристика (угол, базовый балл) |
| Средний | ✓ | ✓ | Полная эвристика (центр, «живые» линии) |
| Сложный | ✓ | ✓ | Minimax с alpha-beta pruning + эвристика |

**Простой** — ИИ замечает собственный победный ход, но не
блокирует угрозу игрока. Для выбора хода использует упрощённую
оценку (без бонуса за центр и «живые» линии).

**Средний** — ИИ ищет победный ход, затем блокирует угрозу X,
затем выбирает клетку с максимальной эвристической оценкой
(бонусы за центр, углы, незаблокированные линии).

**Сложный** — ИИ дополнительно просматривает варианты на 2 хода
вперёд с помощью алгоритма minimax и отсечением alpha-beta.
Число рассматриваемых ходов ограничено, поэтому UI не зависает.

## Требования

- Python 3.11 и выше
- Стандартная библиотека Python (tkinter входит в поставку Python)
- Сторонние зависимости отсутствуют

## Запуск

```bash
python main.py
```

## Запуск тестов

```bash
python -m unittest discover
```

Все тесты выполняются без графического окружения (tkinter не
импортируется в тестируемых модулях `game.py` и `ai.py`).

## Подсказка

Кнопка **«Подсказать ход»** вычисляет и подсвечивает рекомендуемую
клетку для следующего хода игрока (X).

- Ход **не выполняется автоматически** — игрок сам решает, следовать
  ли подсказке.
- Рекомендуемая клетка подсвечивается зелёным цветом; в строке
  статуса появляется пояснительное сообщение.
- Подсветка исчезает при любом ходе игрока, ходе компьютера, нажатии
  «Новая игра» или победе/ничьей.
- Кнопка недоступна во время хода компьютера и после окончания партии.
- Алгоритм подсказки работает через независимый модуль `HintEngine`
  (файл `hint.py`) с собственным поисковым движком `SearchEngine`
  (файл `search.py`). Он не связан с логикой текущего `AI` — использует
  отдельную константу глубины `HINT_SEARCH_DEPTH` и обобщённый
  алгоритм minimax с alpha-beta pruning для произвольного игрока.

## Правила игры

1. Поле 5×5 клеток, изначально все пустые.
2. Игрок ходит первым, делая клик по пустой клетке — ставится X.
3. Компьютер отвечает через короткую задержку, ставя O.
4. Побеждает тот, кто выстроит 5 символов подряд:
   - горизонтально,
   - вертикально,
   - по главной диагонали,
   - по побочной диагонали.
5. Если поле заполнено и победителя нет — ничья.
6. Кнопка «Новая игра» сбрасывает поле в любой момент.

## Архитектура

Зависимости идут строго в одну сторону:

```
ui.py / main.py  →  game.py / ai.py / hint.py  →  constants.py
                                hint.py  →  search.py  →  game.py
```

`game.py`, `ai.py`, `search.py` и `hint.py` не импортируют `tkinter`
и не знают о виджетах — это делает игровую логику полностью
тестируемой в изоляции.
